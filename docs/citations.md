# Third-Party Citations and Licenses

This document registers all external libraries, code fragments, assets, or resources utilized in the Food Pantry SDG-1 Application.

---

## 1. ScalaFX Library
- **Resource URL**: https://github.com/scalafx/scalafx
- **License**: BSD 3-Clause License (https://opensource.org/licenses/BSD-3-Clause)
- **Role**: Standard object-oriented wrapper for JavaFX, used for constructing all views and side-bar navigation nodes.

## 2. OpenJFX (JavaFX) Platform Libraries
- **Resource URL**: https://openjfx.io/
- **License**: GPLv2 with Classpath Exception (http://openjdk.org/legal/gplv2+ce.html)
- **Role**: Java platform GUI controls, layouts, charts, and bindings which serve as the engine backing ScalaFX.

## 3. ScalaTest Framework
- **Resource URL**: https://www.scalatest.org/
- **License**: Apache License, Version 2.0 (http://www.apache.org/licenses/LICENSE-2.0)
- **Role**: Testing framework used for unit testing models and matching algorithms.

The project contains no other external assets or copied source code files. All domain logic, serialization, and UI design were authored originally.
